GAIA Agent: Agents Course Unit 4

Source code of a tool-calling research agent for the Hugging Face Agents Course final assignment (20 GAIA level-1 questions). The agent runs locally; this static Space hosts the code.

Browse the code. Setup, commands, architecture and limitations are in the README.

Files

  • gaia_agent/agent.py: agent loop (OpenAI Responses API or Gemini) and answer extraction
  • gaia_agent/tools.py: search, web/PDF fetch, Wikipedia (dated revisions), sandboxed Python, attachments, media
  • gaia_agent/llm_openai.py, gaia_agent/llm.py: model clients, retries, cost tracking and budget cap
  • gaia_agent/scoring_api.py: course scoring API client and payload validation
  • cli.py: fetch / smoke / run / review / validate / submit
  • app.py: the course template's Gradio UI wired to this agent
  • tests/test_offline.py: offline tests

No API keys, run logs or answers are published here.
